## Подключение Tecno

1. Откройте ссылку APK на телефоне, скачайте и установите файл. Если Android попросит, разрешите установку приложений из этого браузера.
2. Подключите телефон к той же домашней/рабочей сети, в которой находится компьютер `192.168.100.5`.
3. Откройте установленное приложение `watcher-matrix-check`. Оно покажет development launcher.
4. Выберите обнаруженный сервер или используйте «Enter URL»/ручной ввод адреса: `http://192.168.100.5:8081`. Если используется QR, сканируйте QR именно development client из Metro.
5. После загрузки откроется экран «Matrix · диагностика». Нажмите «Проверить SDK».

Metro уже запущен в текущем сеансе на LAN-порту 8081 с флагом `--dev-client`. Проверено: `/status` возвращает `packager-status:running`; Android-манифест отдаёт проект `watcher-matrix-check` и Android bundle URL с тем же LAN-адресом.

Development deep link текущего сеанса:

```text
exp+watcher-matrix-check://expo-development-client/?url=http%3A%2F%2F192.168.100.5%3A8081
```

Если Metro позже остановится, снова запустите в папке проекта:

```powershell
$env:REACT_NATIVE_PACKAGER_HOSTNAME = '192.168.100.5'
npx expo start --dev-client --lan --port 8081
```

При смене сети IP компьютера может измениться. Если телефон не подключается, проверьте одинаковую сеть и доступ Node через Windows Firewall.

## Что считать успешной проверкой SDK

На экране должны появиться:

- «Нативные вызовы выполнены»;
- непустой фактический Rust SDK SHA;
- `#matrix-probe:example.org → true`;
- `not-a-room-alias → false`.

Это реальные вызовы `sdkGitSha()` и `isRoomAliasFormatValid()` через нативный Rust SDK. Matrix-аккаунт, токены и сервер не используются.
