# Сохранение входа на телефоне

Добавлено 4 октября 2026 после подтверждения пользователем шифрования и расшифровки на Tecno.

Владелец подтвердил сохранение сессии, а затем автовход и обновлённый интерфейс на телефоне: «всё как надо». При сохранённой сессии приложение автоматически открывает аккаунт. Текущий статус закреплён сверху, результаты и подробности ошибок расположены перед формой. Кнопка входа использует синюю заливку без обёртки Link, которая теряла функцию стилей Pressable.

Чтение старого зашифрованного сообщения после полной остановки приложения также подтверждено владельцем на Tecno 04.10.2026: [сценарий и результаты](MATRIX_RESTART_TEST.md).

## Что сохраняется

- Пароль не сохраняется. После первого входа используются access token и, если выдан сервером, refresh token.
- SecureStore хранит токены, user ID, device ID, server URL, случайную passphrase хранилища и ID двух тестовых комнат. Веб-версия не сохраняет нативную сессию.
- Нативный SDK использует `SqliteStoreBuilder(dataPath, cachePath).passphrase(...)` вместо временного хранилища для авторизованного клиента. Случайная passphrase — 32 байта из `expo-crypto`. Каждый вход получает отдельный каталог в `Paths.document`; URI переводится в путь ОС для Rust.
- `Client.restoreSession()` возвращает тот же device ID и открывает те же данные и ключи. Если файлы SQLite отсутствуют, приложение требует новый вход вместо молчаливого создания ключей для прежнего устройства.
- `ClientSessionDelegate` сохраняет обновлённые токены. Записи, чтение и удаление проходят одну очередь: запоздалое сохранение не должно вернуть вход после выхода.
- Закрытие экрана освобождает клиент и сохраняет вход. «Выйти» сначала завершает сессию на сервере, затем удаляет защищённую запись и файлы. Ошибка связи при выходе сохраняет возможность повторить выход.
- При ошибке восстановления доступно повторное восстановление или «Забыть сохранённый вход». Второй вариант удаляет локальную сессию и ключи без отзыва серверного устройства; его можно удалить отдельно в настройках Matrix-аккаунта.
- Android Auto Backup отключён в конфигурации; резервное копирование, перенос ключей, доверие между устройствами и полная история не реализованы.

## Установка и проверка

Нужен новый development APK с `expo-secure-store ~57.0.4`, `expo-file-system ~57.0.7` и `expo-crypto ~57.0.3`. Версия Matrix SDK остаётся 0.10.2. Android versionCode — 2.

[Скачать готовый APK](https://expo.dev/artifacts/eas/dgZfokF2HlmDIE27mMmUVu82JNsAyz2kwfwDhsZYJmU.apk). [Успешная EAS-сборка](https://expo.dev/accounts/cprophet/projects/watcher-matrix-check/builds/a47427c0-c432-482c-a42e-a18efe6ae88c).

1. Установите обновлённый APK поверх предыдущего. Откройте проект из development launcher через Metro.
2. Нажмите «Войти в Matrix» и один раз введите тестовый аккаунт на телефоне.
3. Запишите отображаемый device ID. Проверьте шифрование сообщения.
4. Для строгой проверки перезапуска остановите приложение через настройки телефона: «Приложения → watcher-matrix-check → Остановить». Не очищайте данные приложения. Откройте приложение снова. При сохранённой сессии экран аккаунта должен открыться автоматически, без нажатия «Войти в Matrix».
5. Ожидается «Сохранённый вход восстановлен», тот же аккаунт и device ID, без ввода пароля. Повторите проверку шифрования: должна использоваться прежняя тестовая комната.
6. Нажмите «Выйти», закройте и откройте приложение. Теперь должна появиться форма входа.

Это проверка сохранения на одном телефоне. Удаление приложения или очистка его данных на Android требует нового входа. Перенос на другой телефон не входит в этот этап.

После исправления обработки идентификаторов комнат прошли 30 тестов, TypeScript, lint и Android-экспорт. Сохранение сессии, автоматическое открытие аккаунта и новый интерфейс подтверждены владельцем на телефоне. Сохранение прежнего device ID и чтение старого шифротекста после полной остановки подтверждены успешным новым сценарием: он проверяет совпадение устройства, события и контрольной суммы реально расшифрованного текста.

После изменения кнопки, расположения статусов и автоматического перехода повторно прошли TypeScript, lint, все 20 тестов и Android-экспорт с Hermes (`.expo/ui-auto-login-export`). Первая попытка экспорта в изолированном процессе завершилась `spawn EPERM`; повтор с разрешённым запуском компилятора прошёл. Metro отвечает по `http://192.168.100.5:8081/status`. Новая EAS-сборка не запускалась; обновление интерфейса доступно после Reload установленного development client.
