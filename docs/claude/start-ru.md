# Как перенести работу в Claude Code (на Blade)

## 1. Установить Claude Code (один раз)
Открой PowerShell (не CMD) и выполни:
```
irm https://claude.ai/install.ps1 | iex
```
Потом открой новое окно PowerShell и проверь: `claude --version` должен показать номер версии.
При первом запуске `claude` войди тем же аккаунтом Claude, что и здесь.
Если удобнее окно, а не терминал: в приложении Claude на ПК есть вкладка Code, там выбирается эта же папка.

## 2. Обновить папку проекта
```
cd "C:\Users\qtas5\Documents\Codex\2026-10-02\new-chat\watcher-matrix-check"
git status
git remote -v
```
- `git remote -v` покажет github.com/code-of-stalker/watcher или code-of-stalker.github.io. Подходят оба адреса.
- Если `git status` пишет `nothing to commit, working tree clean`:
  ```
  git fetch origin
  git switch main
  git pull --ff-only
  ```
- Если есть изменённые файлы или `pull` выдаёт ошибку, ничего не удаляй. Запусти `claude` в этой
  папке и напиши: «Приведи папку к origin/main, мои локальные изменения сохрани в отдельной ветке».
- Под рабочим VPN GitHub закрыт, поэтому `fetch`, `pull` и `push` работают только без VPN.

## 3. Запуск
```
cd "C:\Users\qtas5\Documents\Codex\2026-10-02\new-chat\watcher-matrix-check"
claude
```
При первом запуске:
- На вопрос, доверяешь ли ты папке, ответь Yes.
- Claude Code предложит подключить сервер `context7` из файла `.mcp.json`. Разреши: он нужен для правила «Rust через Context7».
- Один раз введи `/effort xhigh` (твоё правило по умолчанию). Claude Code его запомнит.
- Введи `/context`: в списке должны быть `CLAUDE.md` и `AGENTS.md`. Это правила проекта, они загружаются сами.

Пиши по-русски, как здесь. Claude отвечает по-русски.

## 4. Как держать контекст маленьким
- `/context` показывает, чем занят контекст и сколько места осталось.
- `/compact` сжимает переписку в короткое резюме, и работа продолжается. Можно сказать, что сохранить:
  `/compact оставь решения по сцене и номера коммитов`.
- `/clear` начинает с чистого листа. Старый разговор можно вернуть через `/resume`.
- Простое правило: одна задача — одна сессия. Задача закончена: `/handoff`, потом `/clear`.
  Задача длинная и контекст занят больше чем наполовину: `/compact`.
- `CLAUDE.md` и правила загружаются заново и после `/clear`, и после `/compact`, поэтому правила не теряются.
  Состояние работы хранится в `docs/claude/state.md`, его пишет `/handoff`.

## 5. Команды проекта
- `/new-scene Сила Зова` — новая анимация для страницы: 2–3 варианта, потом живой прототип в Тишине, потом остальные темы.
- `/ship-to-main` — выкатить на сайт после твоего «пушим».
- `/handoff` — записать, где остановились, перед `/clear`.
- Esc останавливает Claude. Двойной Esc откатывает к прошлому сообщению.
- Скриншот можно перетащить в окно терминала или написать путь к файлу.

## 6. Что изменится
- Прототипы анимаций появляются в папке проекта: `output/prototypes/<сцена>/index.html`. Открываешь двойным кликом.
- Claude Code спрашивает разрешение перед командами. На безопасные (проверки, сборка) можно ответить
  «Yes, and don't ask again». На `git push` лучше отвечать каждый раз.
- На сайт (`main`) идёт только то, на что ты сказал «ок», как и сейчас.
- Проект здесь остаётся: файлы в Library и старые треды никуда не денутся. Облачные треды читают тот же `CLAUDE.md`.
