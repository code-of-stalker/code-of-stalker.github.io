# В облаках — отдельный моушен-этюд

16-секундная зацикленная анимация утверждённой чёрно-золотой иллюстрации.
Герой парит, немного тянется рукой вперёд; галстук, полы пиджака и ноги двигаются
с разными фазами. Облака перемещаются с учётом глубины, четыре символа независимо
покачиваются и подсвечиваются, редкие золотые блики поддерживают движение.

Во второй версии матричный дождь движется отдельными потоками с разной скоростью;
статичные символы удалены из фонового слоя. Два разнесённых по времени порыва
ветра отклоняют облака и дождь, колышут одежду и отдельные пряди волос, переносят
частицы. Лицо сохраняет форму. Между порывами диагональный проход сканера на
короткое время проявляет самостоятельный векторный слой и возвращает живопись.
Кнопки «Сканер» и «Контуры» запускают проход вручную и показывают чистые грани.
Ручной проход не накладывается на автоматический.

Сцена подключена в веб-приложении: шаг 4, «Где ты сейчас?» (`grounding-here`).
Сканер и векторные грани принимают акцент текущей темы. Грани видны только в
коротком следе за сканером: под ними яркость иллюстрации плавно снижается на 42%,
затем возвращает исходную яркость. Светлая линия сканера сохраняет акцентный цвет.
Все четыре края мягко переходят в фон темы. При уменьшении текстур используются
mipmap-уровни, чтобы мелкая гравировка не мерцала на телефоне. Сила движения по
умолчанию — 1,5, максимум прототипа. Компонент останавливает Rust-рендерер вне
экрана и при уходе из приложения; при уменьшенном движении показывает исходный кадр.
Нативное приложение сохраняет существующую иллюстрацию этого раздела.

## Исходники и воспроизводимость

- `assets/original.png` — неизменённая иллюстрация v2.
- `assets/poster.png` — запасной статичный кадр с прозрачными краями, подготовленный на Rust.
- `assets/background.png` — фон с восстановленными областями под героем и символами.
- `assets/hero.png` — отдельный персонаж с настоящим альфа-каналом.
- `assets/background-clean.png` — фон без неподвижных столбцов кода.
- `assets/edges.svg` — самостоятельный векторный рисунок граней.
- `assets/contours.bin` — те же полилинии для GPU, без растрового фильтра во время анимации.
- `examples/vectorize.rs` — воспроизводимое извлечение и упрощение контуров на Rust.
- `examples/poster.rs` — статичная маска с тем же переходом по краям, что у шейдера.
- `assets/layer-prompts.md` — запросы встроенного ImageGen для подготовки слоёв.
- `src/lib.rs` — чистые периодические траектории и их проверки.
- `src/browser.rs` и шейдеры — Rust/WebGL2-рендерер. JS передаёт события,
  размеры, время и настройки доступности; в нём нет реализации сцен или движения.

Версии wasm-bindgen/web-sys/js-sys соответствуют уже используемым версиям
основного Rust-движка. Новый crate изолирован, зависимости приложения не меняются.
Весь цикл детерминированный, 16 секунд; бесконечное накопление времени исключено.
При скрытии страницы или уходе со сцены рисование останавливается. Настройка
уменьшения движения показывает исходную иллюстрацию, сравнение и пауза доступны явно.
Изображение сохраняет пропорции на телефонах и в полноэкранном режиме.

Из корня проекта:

```powershell
./graphics/cloud-drift/build.ps1
node graphics/cloud-drift/package.mjs
node graphics/cloud-drift/serve.mjs
node graphics/cloud-drift/qa.mjs
node graphics/cloud-drift/qa-effects.mjs
node graphics/cloud-drift/export.mjs
node graphics/cloud-drift/verify-video.mjs
```

Предпросмотр: <http://127.0.0.1:8976/>.
Готовый комплект: `output/motion/man-in-clouds/`.
Экспорт: `cloud-drift.mp4`, AVC/H.264, 1536 × 1024, 30 кадров/с, 16 секунд, без звука.
Экспорт захватывает этот же Rust-рендерер; отдельной видеоанимации в JS нет.

## Проверка

Rust: форматирование, тесты периодичности/границы цикла и недопустимых входов,
Clippy с запретом предупреждений, сборка WASM. В основном проекте — lint и TypeScript.
Браузер: desktop 1200 × 930, 393 × 780 и 320 × 568, движения между кадрами,
нулевая разница первого и последнего кадра, отсутствие ошибок GPU/консоли,
пауза, исходник и уменьшение движения. Отчёт и кадры — в `qa/` готового комплекта.
Физический телефон и встраивание в экран приложения — отдельные этапы.

Для второй версии отдельно проверяются движение дождя независимо от камеры,
влияние ветра, проявление контуров, кнопки и декодирование/перемотка MP4.
Сохранённые версии до изменений: `cloud-drift-v1.mp4` и `source-v1.zip` в папке
готового комплекта. Исходная иллюстрация не перезаписывается.
