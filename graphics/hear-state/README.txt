Услышь своё состояние — анимация для шага 4, страница 05/15 (веб)

Сидящий человек (утверждённый контур spoken-thought-person.svg), ступни на полу.
Вдох проходит от носа вниз, человек говорит вслух — голос спокойно уходит
в комнату (на фразу всего три фронта), и человек слышит себя: ухом и изнутри.
Затем страница спрашивает по одному слову: «ЕСТЬ ЛИ В НЁМ — УВЕРЕННОСТЬ?
ТРЕВОГА? МАСКА? ОТСУТСТВИЕ? АВТОМАТИЗМ?». Для каждого слова спокойный скан
проходит по всему телу, от макушки до ступней, и уходит в пол. Сцена нигде
не показывает, где живёт состояние: человек чувствует и определяет сам.
Пять фраз — пять слов из текста страницы. Бесшовная петля 56 секунд.

Всё движение считается в Rust (src/lib.rs — хореография, камера, голос, скан;
src/geometry.rs — меши). Шейдеры только рисуют: сцена пишет каналы света
(голос, «я»), тело и прозрачность, затем блум и композит раскладывают их по
цветам темы. Тёмные темы светят в тёмной комнате, светлые (Дюна, Мираж,
Рассвет) кладут чернила на светлую страницу — одни и те же входные данные.

assets/figure.png — контур фигуры (красный — заливка со стулом, зелёный —
линии, синий — только тело, без стула: скан идёт по нему);
assets/labels.png — слова и вопрос шрифтом Disket Mono;
src/silhouette.rs — края тела по строкам (для меток скана). Пересобрать все три:
  node graphics/hear-state/tools/prepare-assets.mjs   (нужен playwright)

Сборка из корня проекта: ./graphics/hear-state/build.sh (или build.ps1).
Результат — public/graphics/hear-state/. В нативном приложении остаётся
прежняя векторная сцена grounding-voice; она же — запасной вариант без WebGL2.
