Услышь своё состояние — анимация для шага 4, страница 05/15 (веб)

Сидящий человек (утверждённый контур spoken-thought-person.svg), ступни на полу.
Вдох уходит вниз по телу — так глубоко, как позволяет состояние. Голос рождается
в своём источнике внутри тела и поднимается к губам, каждый слог резонирует
внутри (свет виден только сквозь тело), человек слышит себя — ухом и изнутри,
и только потом под вопросом «ИЗ КАКОГО СОСТОЯНИЯ?» состояние названо у груди.
Пять фраз — пять состояний из текста страницы, у каждого свой голос:
уверенность — из живота, до самых ступней, ровно; тревога — дрожь в горле,
мелко и часто; маска — плоский звук сквозь оболочку перед лицом; отсутствие —
пустое кольцо в груди, едва слышно; автоматизм — одинаковые слоги по метроному.
Бесшовная петля 48 секунд.

Всё движение считается в Rust (src/lib.rs — состояния, хореография, камера, волны;
src/geometry.rs — меши). Шейдеры только рисуют: сцена пишет каналы света
(голос, «я»), тело и прозрачность, затем блум и композит раскладывают их по
цветам темы. Тёмные темы светят в тёмной комнате, светлые (Дюна, Мираж,
Рассвет) кладут чернила на светлую страницу — одни и те же входные данные.

assets/figure.png — контур фигуры (красный — заливка, зелёный — линии);
assets/labels.png — названия состояний и вопрос шрифтом Disket Mono. Пересобрать:
  node graphics/hear-state/tools/prepare-assets.mjs   (нужен playwright)

Сборка из корня проекта: ./graphics/hear-state/build.sh (или build.ps1).
Результат — public/graphics/hear-state/. В нативном приложении остаётся
прежняя векторная сцена grounding-voice; она же — запасной вариант без WebGL2.
