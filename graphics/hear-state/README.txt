Услышь своё состояние — анимация для шага 4, страница 05/15 (веб)

Сидящий человек (утверждённый контур spoken-thought-person.svg) говорит вслух.
Голос уходит в глубину комнаты сферическими волнами и тканой лентой, пыль в
объёме подсвечивается фронтом, волна касается одного из состояний — УВЕРЕННОСТЬ,
ТРЕВОГА, МАСКА, ОТСУТСТВИЕ, АВТОМАТИЗМ — и эхо возвращается к уху: человек
слышит своё состояние, свет собирается в груди. Пять фраз, каждый раз отвечает
другое состояние; бесшовная петля 48 секунд.

Всё движение считается в Rust (src/lib.rs — хореография, камера, волны, эхо;
src/geometry.rs — меши). Шейдеры только рисуют: сцена пишет каналы света
(голос, «я»), тело и прозрачность, затем блум и композит раскладывают их по
цветам темы. Тёмные темы светят в тёмной комнате, светлые (Дюна, Мираж,
Рассвет) кладут чернила на светлую страницу — одни и те же входные данные.

assets/figure.png — контур фигуры (красный — заливка, зелёный — линии);
assets/labels.png — подписи состояний шрифтом Disket Mono. Пересобрать:
  node graphics/hear-state/tools/prepare-assets.mjs   (нужен playwright)

Сборка из корня проекта: ./graphics/hear-state/build.sh (или build.ps1).
Результат — public/graphics/hear-state/. В нативном приложении остаётся
прежняя векторная сцена grounding-voice; она же — запасной вариант без WebGL2.
