Знаки ролей в чате Интенсива

Маленький живой знак справа от роли автора в облаке сообщения, 16 px.
Сюжеты Арта (раунд 3 прототипа, 2026-11-11):
- идущий: два следа ног;
- проводник: огонёк света;
- админ: глаз;
- главный админ: гаечный ключ.
В одном чате у человека одна роль, по старшинству для этого чата:
идущий > проводник > админ > главный админ. Яна, ведущая идущего,
в этом чате ПРОВОДНИК с огоньком.

Манера: одна тонкая линия цвета роли (как глифы приложения, 0,75 px
в сетке 24) и слабые заливки. Цвет роли даёт тема: в Тишине проводник
#D9BE86, админ #9FB4E8, главный админ #CDA6E3, идущий — акцент темы;
в остальных темах все роли в акценте. Бледный блик = цвет роли,
смешанный с белым на 0,72.

Ход: цикл 8 с. Знак делает своё движение, потом по контуру пробегает
бледный блик, с 3,5 с до конца цикла покой. Роли сдвинуты по фазе
(идущий 0, проводник 2,1, админ 4,3, главный 6,0), чтобы чат не мигал
разом.
- Следы: оба гаснут, затем ставятся по одному.
- Огонёк: дрожит и вспыхивает, с кончика уходит искра.
- Глаз: моргает (верхнее веко ложится на нижнее), смотрит влево и
  вправо с бликом, затем свет бежит по верхнему веку.
- Ключ: дважды доворачивает, как гайку, со щелчком; затем свет бежит
  по рукояти.
Покой и уменьшение движения: кадр t = 7,0 (ключ ровно на 0°).

Код: всё движение и геометрия в Rust (src/lib.rs, тесты там же).
src/browser.rs создаёт SVG в странице и пишет только изменившиеся
атрибуты; знаки вне экрана, на неактивной вкладке и в покое не
трогаются. Мост src/features/intensive/ui/RoleMark.web.tsx берёт кадры
из общих часов эффектов и сообщает видимость и уменьшение движения.
Нативное приложение показывает знак в покое из
src/features/intensive/ui/roleMarks.generated.ts (его пишет
cargo run --example stills; тест падает, если файл устарел).

Сборка из корня проекта: ./graphics/role-marks/build.ps1 (или build.sh).
Результат — public/graphics/role-marks/pkg (около 85 КБ WASM).
Прототип: output/prototypes/role-marks/index.html.
