Откуда берётся вывод? — отдельная анимация театральной иллюстрации

Источники и назначение
assets/original.png — утверждённая иллюстрация v2.
assets/background.png — восстановленный фон для движения персонажа.
assets/heroine.png — отдельная героиня с альфа-каналом.
src/ — вычисление движения и отрисовка на Rust; браузерный JS передаёт
события, размеры, время и параметры доступности.

Предпросмотр сохраняет соотношение сторон 3:2, поддерживает паузу,
выбор момента, исходник для сравнения и уменьшение движения. Скрытая
или невидимая сцена останавливается. Экспорт использует те же кадры
Rust, затем WebCodecs упаковывает их в H.264/MP4: 1536×1024,
24 секунды, 60 кадров/с, без звука.

Версия 2 — фон и свет
Rust рассчитывает параллакс театра, три мягких перемещающихся луча,
подсветку костюма и пола, движение дымки, 38 цепочек матричного дождя
на трёх планах и 18 крупных частиц перед сценой. Задний дождь закрывается
героиней; ближний проходит по бокам. В точке под ступнями фон закреплён.
Кнопка «Фон и свет» отключает новые слои для сравнения, сохраняя момент
и движение героини. Переключение, пауза и изменение размеров не сбрасывают
таймлайн. Все изменения света и движения вычисляет Rust; шейдеры только
визуализируют переданные параметры и статическую геометрию штрихов.

Исходная версия с проверенной копией видео сохранена отдельно:
output/motion/theatre-marionette-before-atmosphere/

Из корня проекта:
  ./graphics/theatre-marionette/build.ps1
  node graphics/theatre-marionette/serve.mjs

Просмотр: http://127.0.0.1:8978/
Кнопка «Сохранить видео» создаёт:
  output/motion/theatre-marionette/theatre-marionette-atmosphere.mp4
Если предыдущий файл занят видеоплеером, экспорт сохраняет новый MP4
с отметкой времени и возвращает ссылку именно на него.
Сервер слушает только loopback; принимает MP4 до 60 МБ исключительно
из своего origin и только в предусмотренные сервером имена файлов.

?qa — ручной просмотр через шкалу времени без автоматического хода.
?render — только иллюстрация, без элементов управления.
Проверки сборки, браузера и устройства фиксируются отдельно после
их выполнения. Эта папка сама по себе не публикует сайт и не меняет
существующие экраны приложения.


Версия 3 — сайт, шаг 4, страница 03/15
Сила движения по умолчанию 1,5 (максимум). Матричный дождь движется
вдвое медленнее: 24-секундная петля, при прежнем 12-секундном движении
героини, света и фоновых слоёв. package.mjs переносит Rust/WASM и
неизменённые исходные изображения в public/graphics/theatre-marionette.
Сайт использует общий контроллер кадров и качества (плотность 1,50–2,50),
сохраняет сцену при паузе, изменении размера и качества. JS передаёт
события жизненного цикла и собирает диагностику, движение считает Rust.
Нативная версия сохраняет прежнюю сцену; этот релиз предназначен для сайта.
