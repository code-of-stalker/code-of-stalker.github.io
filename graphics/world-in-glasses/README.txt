Мир в очках — анимация иллюстрации Арта для шага 4, страница 01/15

Источники
assets/original.webp — утверждённая иллюстрация (кадр для уменьшения движения
и заставка до загрузки).
assets/background.webp — чистый фон руин (кадр H).
assets/figure.webp — героиня (кадр A) с альфа-маской.
assets/mouths.webp — атлас рта 7×4: жевание (18 промежуточных рисунков между
кадрами A, B, C), губы собираются в «о» (D), лопнувшая плёнка (E) и жвачка
втягивается обратно. Без улыбки в конце.
assets/world.webp — панорама мира в стёклах (кадр G), одна на обе линзы.
assets/lens-mask.svg — маска линз, нарисованная Артом вручную; используется
точно, без автоматической обводки. Размытие по краю σ 2,85 px, как в его макете.

tools/prepare_assets.py пересобирает эти слои из кадров A–H:
  python3 -I tools/prepare_assets.py <папка с кадрами> assets

Движение
Всё движение считается в Rust (src/lib.rs, geometry.rs, glass.rs, lens.rs,
scene.rs): камера, жевание, пузырь, хлопок, трещины, осколки, капли кода,
отслаивающиеся куски стены, камни и пыль. Шейдеры только рисуют переданные
значения. Петля 14 секунд без шва. Жвачка золотая, в палитре картины.

Сборка из корня проекта
  ./graphics/world-in-glasses/build.ps1   (Windows)
  ./graphics/world-in-glasses/build.sh    (Linux, macOS)
Результат кладётся в public/graphics/world-in-glasses/; сайт подхватывает его
на странице 01/15 шага 4. В нативном приложении остаётся прежняя сцена.
