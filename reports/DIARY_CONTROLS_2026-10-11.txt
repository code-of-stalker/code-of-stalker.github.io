Diary controls and storage verification — 2026-10-11

Storage claim verified against implementation and tests
- Web: AES-GCM 256-bit non-extractable CryptoKey, randomized 12-byte IVs,
  authenticated state/audio metadata and 128-bit tags. Encrypted text/state
  and audio blobs are in IndexedDB. The CryptoKey is in that same browser
  profile: this is local encryption, not a separate password lock or backup.
- Native adapter encrypts saved state/audio through expo-crypto and keeps
  its key in SecureStore. Playback temporarily decrypts audio for the player.
- 22 repository/web/native-adapter tests passed. Browser test context verified
  AES-GCM, key length 256, extractable=false and encrypted state contents.
  Native tests use adapters/mocks; no physical device security audit is claimed.
