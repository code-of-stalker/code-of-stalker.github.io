Architecture level selection — 2026-10-11

Requested change
- Intensive uses the same temporary placeholder as Guidance when its Details action is pressed.
- Expanding and collapsing a level must keep its corner cuts stable rather than stretch the entire SVG vertically.

Implementation
- Both unavailable levels use the existing shared modal and return button. The heading identifies the selected level, survives the closing fade, and returning preserves the expanded level. Basic still enters practice through Expo Router.
- Web level contours are drawn in actual CSS coordinates without a viewBox scale. A pure Rust geometry core keeps the upper anchors and cut lengths fixed; only bottom anchors move with layout height. ResizeObserver forwards dimensions to the WASM adapter without per-frame React state or a new rendering clock.
- Fill, outline and scanner glow use the same contour. Cuts remain 45 degrees, the fill follows cut corners, and outlines keep the approved 0.25px / selected 0.75px thickness.
- Native presentation separates fixed top/bottom SVG caps from the straight middle segment so the corner caps do not stretch vertically.
- Height and content transitions share a 620ms easing curve with a gentle start and finish. Existing content fade, scanner reveal, themed palettes, rain, artwork and Guidance spiral are retained. Automatic graphics quality logic was not changed.
