Shared panel contours and Guidance collapse — 2026-10-11

Request
- Restore collapsing Guidance by a repeated title/expand-icon tap.
- Apply and document one resizing rule for product panels in both axes.

Implementation
- The overflowing Guidance spiral's decorative container covered its header and intercepted touches. Its wrapper is now pointerEvents="none"; the header remains above decorative artwork. The spiral scene and overflowing halo are preserved.
- AGENTS.md now requires edge-anchor resizing for frames, glass silhouettes, masks and scanner clips. Corner cuts, notch dimensions, facet widths and stroke widths retain their authored layout-pixel sizes. Approved responsive contour breakpoints remain available.
- Added a pure Rust panel_geometry core, with an equivalent TypeScript adapter for native rendering. Both grow straight spans and translate far-edge points; a genuinely undersized frame may shrink its corner regions uniformly.
- PanelArtwork fits local authored SVG paths into actual layout coordinates. On web Rust owns geometry updates and its adapter owns SVG children; React owns only the host, so parent rerenders cannot replace fitted paths with the original markup. No additional GPU context or animation clock is created.
- Converted Home masks, generic panels/borders, button fallback facets, hint/review frames, observation action frames, step panels/dropdowns and Architecture action frames. Native level frames use nine regions with fixed corner caps. Width-specific Home source contours are retained.
- Step notches now have fixed depths/widths and follow the right edge as the panel widens. Level corner cuts stay 20px across widths and animated heights.
- usePanelSize observes fractional border-box dimensions on web. RN Web onLayout rounded a 339.5px panel to 340px and separated the border/glass path from its mask; exact dimensions now align these surfaces.
- Normal outlines remain 0.25px; the selected Architecture level remains 0.75px. Existing themes, scan reveal, art motion, scroll viewports, placeholder navigation, progress and automatic glass/vector quality policy are retained.
