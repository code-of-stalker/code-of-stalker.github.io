Web themes and updated Architecture — 2026-10-10

Preview: https://furnished-teddy-earl-webmasters.trycloudflare.com/home

Implemented
- Step 2 in Light uses the full-color sand gallery from the user's reference.
  The approved transparent portrait source is a texture atlas, not a video or
  static substitute. Portrait motion, refraction, hero light, particles,
  orbits and matrix movement continue in Rust.
- Neutral theme is enabled and persisted. Its blue/cream palette follows the
  previously developed Laconic theme. Gallery secondary colors are subdued;
  cream remains a local light accent instead of filling the whole figure.
- Scrolling content under fixed headers fades at the viewport edge, including
  the Settings audio-check section. Web uses a CSS alpha mask updated by a
  passive scroll listener without React renders. The native adapter uses an
  Animated gradient; no native-device visual acceptance is claimed here.
- Light icon buttons retain the Rust glass surface and get a 0.10 px SVG
  contour in the theme accent. There is no added GPU glass pass for the outline.
- Architecture Basic, Intensive and Guidance layouts follow the updated Figma
  states, with their exact panel/action contours, notes icon, text and arrow.
  Live Rust animations replace static illustrations. Guidance uses the
  Laboratory double helix named "parallel", not its separate "guidance" junction.
- Web Tektur Medium and SemiBold are explicit instances of the bundled variable
  font (wdth 100, weights 500/600). This fixes WebKit builds which ignore its
  variable weight. Glyphs, spacing and responsive sizing are preserved.
  Native continues using the original variable font. Original OFL is retained.

Rendering and quality
- Palette changes preserve scene IDs, dimensions, draw counters, animation
  clocks, geometry and existing pipelines. Atlas textures/bind groups are cached;
  an unvisited theme's gallery atlas is uploaded only when needed.
- Sand gallery bypasses universal orange duotone recoloring. Neutral coloring
  stays in the existing final presentation shader without another render pass.
- Automatic quality and its glass-first policy were not modified. Glass and
  vector densities remain independent; glass reaches 1 before animation density
  falls. Vector default remains 2.5 and the minimum remains 1.5.
