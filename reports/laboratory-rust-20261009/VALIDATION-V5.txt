ЭКСПЕРИМЕНТ 05 — ПОЛНАЯ СЦЕНА RUST
Проверено 2026-10-09

ГОТОВО
В режиме «Rust · всё» движок Rust/WASM + wgpu рисует всю измеряемую сцену:
стекло, дождь, исходные векторные фигуры «Наблюдающий», движение камеры,
пунктир, свечение, маски, проявление и реакцию стекла на касание.
React оставлен для общих кнопок, настроек, измерений и таблицы результатов.
Перенос остальных экранов Laboratory и нативная Android-интеграция в этот
эксперимент не входят.

Оптимизация:
- Release opt-level=3, LTO, один codegen-unit.
- Геометрия подготовлена в Rust при сборке: 12 372 вершины / 36 990 индексов.
- Фигуры векторные, MSAA 4x; растровый кэш используется только для свечения.
- Дождь: один instanced draw, до 30 обновлений/с, прежний seed и сценарий.
- Нет Canvas2D и SVG в полной Rust-сцене; нет загрузки нового фонового кадра
  из JavaScript каждый кадр. Атласы загружаются один раз при создании движка.
- Буферы, текстуры и графические pipeline переиспользуются.
- Максимальная плотность 2 во всех режимах; автоматического снижения качества
  в замере нет.

ДОСТОВЕРНОСТЬ СРАВНЕНИЯ
Оставлены три режима: исходный, Rust только для стекла, Rust для всей сцены.
Каждый замер пересоздаёт движок и начинается с первого RAF-кадра; подготовка
учитывается отдельно. 15 с прогрева + 45 с измерения, все 12 отрезков по 5 с
остаются в JSON. Долгие кадры не отбрасываются.
Смена размеров/настроек, скрытие вкладки или уход сцены за экран отменяет замер.

Это сравнение оптимизированных реализаций, а не чистый тест языков: меняется
и способ рисования. Для одинакового GPU API предусмотрен «Rust через WebGL2».
Во всех режимах v5 одинаковые шрифты дождя, область иллюстрации и скорость
анимации по активному времени. Предыдущие результаты v4 не смешивать с v5.

ПРОЙДЕННЫЕ ПРОВЕРКИ
- GLSL → WGSL: стекло и размытие; Naga: новый шейдер полной сцены.
- 6 тестов Rust; 12 тестов JS; TypeScript и ESLint эксперимента.
- npm run typecheck и npm run lint основного проекта.
- Release WASM и production web build.
- Запуск полной сцены через WebGPU и принудительно через WebGL2 в Chrome.
- Кадры на 0, 5.6 и 7.5 с сопоставлены с исходной анимацией: те же формы,
  положение фигур, приближение, перекрытие и сценарий свечения. Растеризация
  краёв и мягкий свет могут немного отличаться; это не пиксельная идентичность
  и не визуальное утверждение пользователем.
- На публичной HTTPS-странице проверен запуск финального WASM через WebGPU.
  В области сцены один canvas и ноль SVG.
- В локальную Laboratory установлен тот же WASM и JS; SHA-256 совпадают.
